# منيو مشويات الباشا – EL BASHA GRILL

موقع ثابت بالكامل (HTML + CSS + JavaScript) بدون Backend أو قاعدة بيانات، مناسب للنشر المجاني على GitHub Pages.

## الملفات

- `index.html` : هيكل الصفحة (الواجهة الرئيسية، السلة، الفوتر).
- `style.css` : التصميم والأنيميشن.
- `script.js` : بناء المنيو، التنقل، السلة، رسالة واتساب، الشرارات.
- `menu-data.js` : كل الأصناف والأسعار (لتعديل سعر أو إضافة صنف عدّل هذا الملف فقط).
- `logo.png` و `logo.webp` : لوجو المطعم.

## سلة الطلب

- كل صنف (وكل حجم) له زر أضف، والكمية تتغير من الأزرار + و −.
- يظهر شريط أسفل الشاشة بعدد الأصناف والإجمالي، ومنه تفتح نافذة مراجعة الطلب.
- في النافذة: نوع الطلب (استلام من المطعم / توصيل)، الاسم، العنوان (يظهر مع التوصيل)، ملاحظات.
- زر إرسال الطلب يفتح واتساب مباشرة على الرقم 01007475474 برسالة منسقة جاهزة.
- الطلب يُحفظ في متصفح العميل ولا يضيع عند تحديث الصفحة.

لتغيير رقم واتساب غيّر `WA_NUMBER` في أول `script.js` (بصيغة دولية بدون +).

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع كل الملفات في الجذر.
2. من Settings ثم Pages اختر Deploy from a branch، ثم الفرع main والمجلد root.
3. بعد دقيقة يظهر الرابط في نفس الصفحة.
